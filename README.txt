迷いの森 / MAYOI NO MORI — 神社・洞窟版

今回の修正：v3.2：トンネルを元GLBからUVを保持して再変換しスキャンの浮遊片を除去／神社を元モデルの2.2倍に拡大し衝突判定更新／紅葉42本をインスタンス描画／新しい白い顔を初期設定に再適用／JSと素材名に内容ハッシュを付与。

設置：このフォルダーの index.html、js、assets を同じ階層のまま GitHub Pages にアップロードしてください。npm やビルドは不要です。
必要なプログラム・画像・音声・軽量化モデルはすべて同梱されています。外部CDNへの接続は不要です。
ローカル一式を保持すればオフラインで動作します。GitHub Pagesのページを閲覧しただけで自動的にオフライン保存するPWAではありません。

ゲーム：森4・神社境内1・社殿内1・洞窟1、合計7部品を集めます。
墓地にある別枠の鍵を拾い、南のゲートで解錠し、BMWを調べるとトンネルから脱出します。
ライトは常時点灯。電池を拾って補充します。移動中も取得できます。
移動パッドは通常移動の感度を保ち、走行開始72px・歩行復帰58pxに調整しています。
通常の敵顔は新画像。ランダムONでは旧5枚を40/15/15/15/15%で開始時に選び、その探索中は固定します。
攻略マップは実装したエリア座標から作成しています。

素材：添付GLBの形状とテクスチャを縮尺・接地調整し、ゲーム用データへ変換しました。
assets/world-assets.[ハッシュ].js に神社・鳥居・墓石・灯籠・樹木2種・BMW・トンネルのデータを格納しています。
元の簡易鳥居・バイク・祠の形状を代用品として表示する処理はありません。
トンネルは添付スキャンの入口部分を切り出し、樹木・バイク等の形状とテクスチャは軽量化しています。
作者とライセンスはゲーム内の操作説明「3D素材のクレジット」を参照してください。

検証と制限：
・8素材・21配置モデルと42本の紅葉をThree.js上で組み立て、全テクスチャ画像のデコードを検査。
・100回のランダム配置、全新規候補への往復経路、鍵の墓地限定を検査。
・取得、電池補充と消費、常時ライト、解錠、脱出、死亡、再挑戦、一時停止、移動中の取得を検査。
・顔の抽選比率、移動パッド境界、ノイズの表示上限と恐怖軽減時の停止を検査。
・3地点を10度刻みで水平レイ検査し、外周方向に遮蔽物があることを確認。
・上記はGPUを使用しないコード・形状検証です。
・確認用Chromeでは GL_RENDERER=Disabled / Error creating WebGL context のため3D画面を起動できませんでした。
・実画面でのモデル表示・接地・明るさ・360度の見え方・追跡中の操作感、およびiPhone Safari / Android Chromeでの表示・回転・性能は未検証です。
このため「全端末でプレイ確認済みの完成版」ではありません。
